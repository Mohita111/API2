# Translation extraction

## What translation extraction is

Translation Extraction refers to the capability to collect user-facing text from a product so it can be translated into multiple languages. This capability is intended for developers who build and maintain the product, and for translators who create localized versions for different regions.

## Current status

Translation Extraction is not available in this product. The current release displays all interface text in English only. There is no way to:

- Extract interface text into translation files
- Import translated text
- Switch the product interface to another language
- Preview localized versions of the interface

## Languages in this product

The language options you see while using this product refer to the programming language of a code snippet, not the language of the product interface. These options include JavaScript, Python, SQL, and Markdown. They determine how your code is colorized and highlighted when you view it, but they have no effect on the language used for menus, buttons, or dialogs.

## What this means for you

If your goal is to manage and reuse code snippets, all product controls remain fully usable. If your goal is to translate the product interface into another language, that workflow is not currently supported and no workaround exists within the product.

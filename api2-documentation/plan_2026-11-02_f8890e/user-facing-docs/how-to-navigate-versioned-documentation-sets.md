# How to navigate versioned documentation sets

Versioned documentation shows the instructions and reference content for a specific release of a product. Site visitors normally switch between releases with a **Version selector** near the top of a documentation page, then read the pages that belong to the selected version.

> [!IMPORTANT]
> The product build reviewed for this guide doesn't include a version selector for documentation sets. Because we can't verify the actual menu labels, available versions, or behavior, the step-by-step switching procedure isn't listed here. Don't follow version-switching steps written for another product—the labels and location can differ.

## What you can do now

Until version switching is available in this product, you can still move through the documentation in two verified ways:

1. Use the documentation sidebar to browse topics by section.
2. Use the search bar to find a specific page or term.

For detailed steps, see:

- [How to browse documentation by sidebar](doc:526a2eef-f1ec-498a-ba05-8f9a60a0241a)
- [How to search documentation content](doc:618bed8b-55ea-4ed4-9526-f90adade00c3)

## Expected result

When a **Version selector** becomes available, picking a version should display only the pages and content that belong to that release. Since the selector isn't present in the current reviewed build, this behavior can't be confirmed here.

## Common issues

Verified common issues can't be listed for the version selector because the feature isn't present in the current build. If you need version switching, check the product release notes or contact your site administrator.
